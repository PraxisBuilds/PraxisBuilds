# Hey, I'm Praxis 👋

I build practical, privacy-respecting software, mostly on Linux.

My background is in land surveying and field operations, where precision, reliable workflows, and useful tools matter more than flashy features. I'm bringing that same mindset into software development: identify a real problem, build something that helps, and keep improving it through testing and feedback.

## What I'm building

- **Logi-GHub Linux** | Extending and testing a Linux tool for configuring Logitech gaming devices. My current focus is safer profile workflows, GUI behavior, regression testing, and protecting working device settings.
- **KeyTrail** | A local desktop app for reviewing typing-test results, including WPM, accuracy, and consistency. No account or cloud upload required.
- **Shelfwish** | A local-first collection ledger for books, games, movies, and music, with catalog filters, exports, and backup/recovery features.
- **Atlas** | An early-stage C++20 survey, CAD, and GIS engine, starting with coordinate geometry, traverse calculations, closure checks, and automated tests.
- **Steady** | An early-stage Android shopping companion exploring straightforward, accessible, offline-first budgeting workflows.

*These projects are at different stages of development, and their repositories are currently private.*

## How I work

- **Problem-first:** I build tools around workflows I know or problems I actually encounter.
- **Test and verify:** Reproduce bugs, make focused changes, check regressions, and protect working behavior.
- **AI-assisted, hands-on:** I use AI coding tools to help implement ideas, while I work through requirements, inspect code, test changes, and learn the fundamentals.
- **User control:** Favor local data, repairability, accessibility, and software that doesn't demand an account or subscription.
