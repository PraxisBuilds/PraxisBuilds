# Praxis

Independent developer building practical, privacy-respecting software.

My background is in land surveying and field operations. I’m particularly interested in turning complicated real-world workflows into calm, dependable tools.

## What I’m building

- **KeyTrail** — A privacy-focused desktop application for understanding typing habits and progress. Version 0.1.0 shipped.
- **Steady** — An accessible Android shopping companion designed around focus, simplicity, and user ownership.
- **Atlas** — A Linux-first survey, CAD, and GIS engine exploring geometry, coordinate workflows, and field-to-office tools.

## How I build

- Privacy by default
- Accessibility as a core feature
- No ads, invasive telemetry, or subscription dependence
- Useful software that people can simply own
- Careful iteration informed by real-world needs
